# Portafolio - Evelyn Sepúlveda Varela

Portafolio web estático desarrollado con HTML, CSS, Bootstrap y JavaScript.

## Estructura

```text
portafolio_evelyn/
├── index.html
├── css/
│   └── style.css
└── js/
    └── script.js
```

## Tecnologías

- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript
- Bootstrap Icons

## Publicación en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube `index.html`, la carpeta `css` y la carpeta `js`.
3. En GitHub entra a **Settings > Pages**.
4. En **Build and deployment**, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Guarda los cambios.
6. GitHub generará la dirección pública del portafolio.

Los enlaces de GitHub y LinkedIn ya están configurados.

## Nota

El portafolio no contiene demos desplegadas de los proyectos, porque actualmente los proyectos se presentan mediante sus repositorios de GitHub.
